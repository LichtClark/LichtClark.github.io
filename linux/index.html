Ein vollständiger x86-PC in einem Browser-Tab. Kein Konto, keine Installation, kein Server: Kernel und Emulator sind statische Dateien, gerechnet wird in WebAssembly auf deinem Gerät.

Volles Linux

Alpine Linux 3.24

Ein echtes Linux mit Paketverwaltung: apk add bash curl git python3 …. Mit optionaler Festplatte bleibt alles im Browser erhalten.

  • apk mit knapp 6000 Paketen (über Relay)
  • Login bis Prompt in ~30 s
  • persistente Platte in IndexedDB
  • erster Start lädt einmalig ~65 MB

Blitzschnell

Buildroot 6.8

Winziges Linux mit BusyBox-Shell – bootet in wenigen Sekunden. Ideal zum schnellen Ausprobieren, wenn es kein volles System sein muss.

  • nur 10 MB – startet fast sofort
  • Shell auf serieller Konsole (xterm.js)
  • Lua, ping, curl an Bord
  • läuft auch auf schwächeren Geräten

Grafischer Desktop

Tiny Core 10.1

Vollwertiges Linux mit FLTK-Desktop in 18 MB. Der Autostart bestätigt das Boot-Menü, danach erscheint die Oberfläche von selbst.

  • grafischer Desktop (Xvesa/flwm/wbar)
  • bootet in unter einer Minute
  • Netz per sudo udhcpc

X11-Klassiker

Damn Small Linux

Der 50-MB-Klassiker mit vollständigem X11-Desktop: Fenstermanager, Dateimanager, Dillo-Browser – alles mit der Maus bedienbar.

  • kompletter Desktop mit Maus
  • DHCP verbindet sich beim Boot von selbst
  • Knoppix-Basis, Kernel 2.4

Kuriosum

KolibriOS

Ein grafisches Betriebssystem, komplett in Assembler geschrieben – passt auf eine 1,4-MB-Diskette und bootet praktisch sofort zum Desktop.

  • ganzes OS auf einer Diskette
  • Editor, Dateimanager, Spiele, Demos
  • bedienbar mit der Maus

FreeDOS

Die klassische DOS-Eingabeaufforderung von einer 722-KB-Diskette. Der Autostart zeigt den Disketteninhalt – Spiele inklusive.

  • startet in Sekunden zu A:\>

So funktioniert es

v86 emuliert einen kompletten 32-Bit-x86-Rechner und übersetzt dessen Code zur Laufzeit nach WebAssembly – schnell genug, um damit zu arbeiten. Tastatur und Maus gehen an die VM, sobald du den Bildschirm anklickst. Willst du ins Netz, lässt sich in der Oberfläche ein Relay zuschalten (echtes TCP/IP); dessen Betreiber sieht dann den Verkehr der VM – das steht auch so in der App. Ohne Relay bleibt alles im Tab.

Läuft am besten …

… in aktuellem Chrome, Edge oder Firefox am Desktop. Auf dem Handy funktioniert es, ist aber langsamer, und die Tastatur ist fummelig. Der Tab sollte im Vordergrund bleiben – im Hintergrund drosselt der Browser die Zeitgeber und der Bootvorgang stockt.

Es gibt noch mehr

Auch eigene ISO-Abbilder lassen sich booten („Eigenes Abbild“ in der Systemauswahl — mit 32-Bit-Prüfung vor dem Start). Nur echtes x86_64 über QEMU-Wasm braucht mehr Daten und besondere Server-Kopfzeilen, als sich hier sinnvoll ausliefern lässt; es steckt in der lokal lauffähigen Vollversion auf GitHub. Wie alles im Detail funktioniert — Emulation, Autostart, Netzwerk, Festplatte — steht in der Dokumentation.
